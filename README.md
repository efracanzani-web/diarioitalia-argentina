# Diario Italia Argentina

Edizione argentina di [Diario Italia](https://diarioitalia.org): la selezione quotidiana delle notizie della collettività italiana in Argentina, in spagnolo (versione principale) e italiano.

- `public/index.html` – la pagina del portale
- `public/data/news.json` – il numero del giorno (aggiornato ogni giorno)
- `fonti.json` – le fonti monitorate (media, istituzioni, associazioni, con siti e profili Facebook/Instagram)
- `REDAZIONE.md` – le regole per preparare il numero
- `wrangler.jsonc` – configurazione di Cloudflare Workers

Pubblicato su https://argentina.diarioitalia.org
